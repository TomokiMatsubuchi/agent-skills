# Shared Hello

This skill demonstrates a single source of truth for multiple AI coding CLIs.

## When to use

- The user asks for a greeting.
- The user wants to confirm that the shared skill sync is working.

## How to respond

Reply with a short, friendly greeting in the same language the user is using, and mention which CLI you are running from.
